# What tools/publish/publish_decomp.py may push to github.com/SadBoxMan/twinblade (r155, docs/publishing.md).
#
# The GitHub repository holds the DECOMP only. The recompiler, the PC port and every ripped asset stay local.
# One rule per line: "+ <pattern>  # reason" allows, "- <pattern>  # reason" denies. A path goes out only when it
# matches an allow rule and no deny rule (deny always wins); anything not allowed stays local.
# Patterns are paths from the repository root: "dir/" is the whole folder, "*" matches within one path segment,
# "**" across segments. Paths are compared case-insensitively.
# To add something, add an allow rule here, run `publish_decomp.py --report` and read what changed before publishing.
